# pigCW

Run as `python -m src.vail`.

This is still rather scrappy. It is a terminal-only Vail client for keying and hearing Morse over the internet through a Raspberry Pi and `pigpio`.

Connect your key and a buzzer to the Pi and it becomes a rather direct little Vail terminal.

The name pigCW is a bad pun between ham and pigpio - the main IO library - often misread as "pig pio".

There is no proper keyer yet. At this stage it is straight-key input, upstream timing, and a buzzer so you can hear what the thing is doing.
